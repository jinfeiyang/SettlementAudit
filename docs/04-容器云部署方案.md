# 通信工程造价结算 AI 预审分析工具 —— 容器云部署方案

> 依据中国联通容器云平台使用指引整理，落地到本系统（测试租户「智创工坊-揭榜」）的部署操作方案。

---

## 1 平台概述

- 容器云平台 = **K8s 集群 + 联通定制可视化界面**，用于应用容器化部署。
- 优势：资源分配灵活、多服务器统一管理、容器故障自动迁移。
- 容器是镜像的运行实例（独立进程与隔离环境）；镜像是只读"模板"，打包应用代码、依赖与运行环境。

## 4 镜像制作与发布流程

### 4.1 本地准备

1. 本地安装 Docker Desktop。
2. 登录镜像仓库（需先申请容器云账号）：
   ```bash
   docker login 130.36.8.236:8443 -u<容器云用户名> -p<容器云密码>
   ```
3. 拉取基础镜像：
   ```bash
   docker pull 130.36.8.236:8443/library/uos-server-20-1070u1a:latest
   ```

### 4.2 Dockerfile 示例（解析/AI 服务）

基础镜像较精简，需配置临时 yum 源并写入 /etc/hosts 后安装依赖：

```dockerfile
FROM 130.36.8.236:8443/library/uos-server-20-1070u1a:latest

# 配置临时 yum 源（zcgf-nginx.zcgf-test.com 为临时域名，无内网 DNS，需 hosts 映射 130.36.8.237）
RUN printf '[myuos-BaseOS]\nname=UOS Server BaseOS\nbaseurl=http://zcgf-nginx.zcgf-test.com/myuos/BaseOS\nenabled=1\ngpgcheck=0\n\n[myuos-AppStream]\nname=UOS Server AppStream\nbaseurl=http://zcgf-nginx.zcgf-test.com/myuos/AppStream\nenabled=1\ngpgcheck=0\n' > /etc/yum.repos.d/myuos.repo \
 && echo "130.36.8.237 zcgf-test.com" >> /etc/hosts \
 && yum -y install python3 python3-pip gcc && yum clean all

WORKDIR /app
COPY requirements.txt .
RUN pip3 install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["python3", "main.py"]
```

（Java 后端：同样基于该基础镜像，yum 安装 jdk17 或 COPY 自带 JDK，`java -jar app.jar` 启动。）

### 4.3 构建、验证、推送

```bash
docker build -t 130.36.8.236:8443/<项目命名空间>/<服务名>:<版本>-<日期> .
docker push 130.36.8.236:8443/<项目命名空间>/<服务名>:<版本>-<日期>
```

- 先在本地用 Docker Desktop 构建运行验证，再推送到平台。
- **tag 规范统一**（服务名-版本-日期），保证可回滚、可迁移。

## 5 应用创建与网络

- 在容器云平台创建应用（推荐使用 **132.151.74.0/24** 网段）。
- **持久化**：申请持久化存储（PVC），存放解析产物、规则配置、报告生成中间文件；图纸原文件按涉密要求管控。
- **数据库接入**：通过连接串连接省公司 MySQL 实例（网络需打网申请可达）。
- **配置外置**：连接串、模型地址、密钥等一律走环境变量/平台配置，镜像内不写环境差异。

### 5.2 本项目入口规划

```
用户 --HTTP 80 + 域名--> 全局负载均衡(130.36.8.237) --> preaudit-web:80
                                                          ├─ /      静态资源
                                                          └─ /api/  preaudit-backend:8080
                                                                       └─ preaudit-ai:8000
                                                                     MySQL（省公司实例）
```

- 只有 `preaudit-web` 配对外服务；`preaudit-backend`、`preaudit-ai` 用 ClusterIP 内部通信。
- 一期不部署 Redis（无强依赖），需要时再申请实例。
- 具体参数对照与验收清单见 `deploy/README.md`；YAML 见 `deploy/k8s/`。

### 5.3 域名是前置条件

HTTP 服务类型**强制域名访问**，因此域名必须在 W1 与云资源一并确认（平台分配或申请流程），否则无法提供对外入口。同时确认 80 端口与其他项目的分隔方式（本项目接口统一在 `/api` 前缀下，便于 Uri 映射区分）。

## 6 环境与迁移预案

- 当前：测试环境（「智创工坊-揭榜」租户）。
- 赛后如需保留则迁移：镜像统一从仓库拉取（不依赖本地）；配置全部外置；应用**无状态化**（状态放 MySQL/Redis/PVC），保证迁移可复制、可回滚。

## 7 本方案待确认项

1. 容器云是否提供 GPU 节点（本地部署大模型前提；否则用元景 API）。
2. 在线看图组件（mxdraw）容器化部署与授权。
3. MySQL 实例规格、版本与网络可达性。
4. 云资源申请与打网申请放行周期（影响一期 W1~W2 发布）。
5. **对外域名如何分配**（HTTP 服务类型强制域名，W1 需确认）。
6. 容器云内是否有内网 PyPI 代理（AI 镜像 `pip install` 依赖；否则用离线 wheel）。

### 8.2 必填字段文案

**资源用途**：通信工程造价结算 AI 预审分析工具（一期试用版），面向造价人员提供清单导入标准化、定额套用核查、取费核算、疑点分级复核与预审报告初稿生成。部署于「智创工坊-揭榜」租户，3 个应用（web 前端 / 业务后端 / AI 解析服务），数据库使用省公司统一下发的 MySQL 实例，不部署容器内数据库。

**分应用资源（部署实际值，供评审核对）**：

| 应用 | requests | limits | 说明 |
| --- | --- | --- | --- |
| preaudit-web（nginx） | 100m / 128Mi | 500m / 256Mi | 静态资源 + 接口反代 |
| preaudit-backend（Java） | 500m / 1Gi | 2 / 2Gi | `-Xmx1g`，核查与报告导出 |
| preaudit-ai（Python） | 500m / 1Gi | 2 / 2Gi | DXF 解析 CPU 密集，瞬时吃满 2 核 |
| 合计 | 1.1 核 / 2.13 GiB | **4.5 核 / 4.25 GiB** | 申请 8 核 / 16 GiB 为上述 1.8~3.7 倍冗余 |

**存储依据**：单项目原件 ≤120 MB（图纸 ≤100 MB + 清单 ≤20 MB），按 2 年 300 个项目估算约 36 GB，含报告版本与解析中间文件按 3 倍冗余取 100 GB；AI 解析缓存 50 GB（图纸量算 JSON、临时转换文件，走元景 API 时可压缩至 20 GB）。访问以顺序大文件读写为主，无高 IOPS 要求。

**数据库需求**：MySQL 8.0，建议 2C4G 及以上，最大连接数 ≥50（应用侧 Hikari 上限 20），字符集 `utf8mb4`，需备份策略；建表脚本由我方提供（`backend/src/main/resources/db/schema.sql`）并配合执行，容器环境不自动建表。

**网络需求**：Pod 网段 `132.151.74.0/24`；对外仅 web 一个服务，通过**全局负载均衡（130.36.8.237）+ HTTP 80 + 域名**发布。需网络准入：① M 域终端 → B 域应用域名；② 集群 → MySQL 实例 3306；③ 集群 → 大模型网关（元景 API）。**不需要**独立公网 IP。

**安全合规**：图纸/清单原件仅落持久化存储，不写容器本地盘；接口令牌鉴权 + RBAC + 写操作审计日志；连接串与密钥经平台配置注入，不入镜像；竣工图纸按涉密要求管控。

**不申请项（避免被判定为漏项）**：GPU 节点（一期走元景 API，二期如需本地化大模型再追加）、Redis（一期无强依赖，后续按需）、公网 IP（走平台负载均衡）。

**扩容触发条件与归还**：单应用 CPU 连续 15 分钟 >70% 或就绪探针超时即扩至 2 副本；测试租户赛后迁移时，按迁移方案整体重建或释放配额。
