## 1 平台概述

- 容器云平台 = **K8s 集群 + 联通定制可视化界面**，用于应用容器化部署。
- 优势：资源分配灵活、多服务器统一管理、容器故障自动迁移。
- 容器是镜像的运行实例（独立进程与隔离环境）；镜像是只读"模板"，打包应用代码、依赖与运行环境。

## 4 镜像制作与发布流程

### 4.1 本地准备

1. 本地安装 Docker Desktop。
2. 登录镜像仓库（需先申请容器云账号）：
   ```bash
   docker login 130.36.8.236:8443 -u<容器云用户名> -p<容器云密码>
   ```
3. 拉取基础镜像：
   ```bash
   docker pull 130.36.8.236:8443/library/uos-server-20-1070u1a:latest
   ```

### 4.2 Dockerfile 示例（解析/AI 服务）

基础镜像较精简，需配置临时 yum 源并写入 /etc/hosts 后安装依赖：

```dockerfile
FROM 130.36.8.236:8443/library/uos-server-20-1070u1a:latest

# 配置临时 yum 源（zcgf-nginx.zcgf-test.com 为临时域名，无内网 DNS，需 hosts 映射 130.36.8.237）
RUN printf '[myuos-BaseOS]\nname=UOS Server BaseOS\nbaseurl=http://zcgf-nginx.zcgf-test.com/myuos/BaseOS\nenabled=1\ngpgcheck=0\n\n[myuos-AppStream]\nname=UOS Server AppStream\nbaseurl=http://zcgf-nginx.zcgf-test.com/myuos/AppStream\nenabled=1\ngpgcheck=0\n' > /etc/yum.repos.d/myuos.repo \
 && echo "130.36.8.237 zcgf-test.com" >> /etc/hosts \
 && yum -y install python3 python3-pip gcc && yum clean all

WORKDIR /app
COPY requirements.txt .
RUN pip3 install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["python3", "main.py"]
```

（Java 后端：同样基于该基础镜像，yum 安装 jdk17 或 COPY 自带 JDK，`java -jar app.jar` 启动。）

### 4.3 构建、验证、推送

```bash
docker build -t 130.36.8.236:8443/<项目命名空间>/<服务名>:<版本>-<日期> .
docker push 130.36.8.236:8443/<项目命名空间>/<服务名>:<版本>-<日期>
```

- 先在本地用 Docker Desktop 构建运行验证，再推送到平台。
- **tag 规范统一**（服务名-版本-日期），保证可回滚、可迁移。

## 5 应用创建与网络

- 在容器云平台创建应用（推荐使用 **132.151.74.0/24** 网段）。
- **持久化**：申请持久化存储（PVC），存放解析产物、规则配置、报告生成中间文件；图纸原文件按涉密要求管控。
- **数据库接入**：通过连接串连接省公司 MySQL 实例（网络需打网申请可达）。
- **配置外置**：连接串、模型地址、密钥等一律走环境变量/平台配置，镜像内不写环境差异。

## 6 环境与迁移预案

- 当前：测试环境（「智创工坊-揭榜」租户）。

## 7 本方案待确认项

1. 容器云是否提供 GPU 节点（本地部署大模型前提；否则用元景 API）。
2. 在线看图组件（mxdraw）容器化部署与授权。
3. MySQL 实例规格、版本与网络可达性。
4. 云资源申请与打网申请放行周期（影响一期 W1~W2 发布）。
