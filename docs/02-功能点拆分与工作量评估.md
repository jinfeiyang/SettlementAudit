## 3 关键功能点细化说明

### A1 竣工图纸 CAD 矢量解析（复杂）

- 输入：DWG/DXF 竣工图（通信线路、设备安装两类）。
- 处理：DWG→DXF 转换（ODA File Converter）→ 图层/块引用展开/标注（线性标注、多行文字、属性块）提取 → 按规则量算（线缆长度按图层与路径、设备数量按块计数）→ 解析结果入库（图元坐标、类型、所属图层、量算结果）。
- 输出：可结构化分项的量算结果，供 B3 核对、D2 回溯定位。
- 复杂度依据：多格式兼容、标注语义解析、量算规则、异常图纸降级处理。

### B1 定额套用三级核查（复杂）

- 一级精确匹配：清单项目特征 ↔ 定额子目 名称/编码/单位完全一致。
- 二级特征语义召回：不完全一致时，用向量检索与 LLM 语义匹配召回候选定额（排序，供"前三名命中率 ≥85%"指标考核）。
- 三级换算系数校验：定额换算系数（人工×系数、材料调整等）代入校验换算结果。
- 输出：推荐定额列表 + 命中率统计 + 偏差疑点。

### C1 LLM 网关与语义对齐（一般/大模型）

- 网关：模型切换、上下文组装（定额库 RAG 检索 + 图纸说明 + 清单特征）、Toke 约束与结构化 JSON 输出、超时重试、调用审计。
- 对齐：图纸分项 ↔ 清单分项的语义匹配（名称/特征/单位对齐），输出对齐置信度。
- 护栏：金额不写入、不直接下结论；结论字段校验（仅解释/建议级）。

### D2 一键回溯定位（复杂）

- 清单行号回溯：疑点直接关联清单行 → 前端跳转高亮。
- 图纸图元回溯：疑点关联图元 ID → 在线看图组件定位到图元坐标并高亮（依赖 A1 留存图元坐标与 mxdraw 定位能力，一期可先做清单行号回溯）。
